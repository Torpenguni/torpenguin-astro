<h4>Negotiation Skill: ทักษะที่เจ้าของธุรกิจต้องมี ไม่ใช่แค่เพื่อลดราคา แต่เพื่อต่อรองอนาคตของกิจการ</h4>

<h5><strong>Negotiation Skill คืออะไร และทำไมเจ้าของธุรกิจต้องมี?</strong></h5>
<p>เคยรู้สึกมั้ยว่าบางที “กำไร” ของร้านเราไม่ได้มาจากยอดขายเพิ่มขึ้น แต่มาจาก “คำพูดเพียงไม่กี่คำ” ที่เราพูดตอนเจรจา</p>
<ul>
<li>
<p>ลดต้นทุนค่าวัตถุดิบได้ 5% เพราะคุยกับซัพพลายเออร์ดี</p>
</li>
<li>
<p>ได้พื้นที่ร้านที่ดีกว่าในห้างเดียวกัน เพราะรู้จักขอมากกว่าคนอื่น</p>
</li>
<li>
<p>รั้งพนักงานดี ๆ ไว้ได้เพราะคุยกันรู้เรื่อง</p>
</li>
<li>
<p>หรือแม้แต่ขยายธุรกิจได้ เพราะเสนอเงื่อนไขให้นักลงทุนพอใจ</p>
</li>
</ul>
<p>ทั้งหมดนี้ไม่ใช่โชค แต่คือผลของ <strong>ทักษะการเจรจาต่อรอง </strong>ที่เจ้าของธุรกิจทุกคนควรมีไว้ติดตัว</p>
<p>
<hr />
<h5></h5>
<h5><strong>ทำไม Negotiation Skill ถึงสำคัญกับ SME?</strong></h5>
<p>โลกของ SME เต็มไปด้วยการ “พูดคุยเพื่อหาข้อตกลง” อยู่ตลอดเวลา ไม่ใช่แค่เรื่องซื้อ-ขายเท่านั้น แต่รวมถึงการ</p>
<ul>
<li>
<p>ตกลงกับ <a href="https://torpenguin.com/%e0%b8%a7%e0%b8%b4%e0%b8%98%e0%b8%b5%e0%b9%80%e0%b8%a5%e0%b8%b7%e0%b8%ad%e0%b8%81%e0%b8%8b%e0%b8%b1%e0%b8%9e%e0%b8%9e%e0%b8%a5%e0%b8%b2%e0%b8%a2%e0%b9%80%e0%b8%ad%e0%b8%ad%e0%b8%a3%e0%b9%8c/">Supplier</a> เพื่อให้ได้ราคาหรือเงื่อนไขที่ดีที่สุด</p>
</li>
<li>
<p>คุยกับเจ้าของพื้นที่เรื่องค่าเช่าและสัญญาที่ยุติธรรม</p>
</li>
<li>
<p>เจรจากับพนักงานเรื่องเป้าหมายงานหรือผลตอบแทน</p>
</li>
<li>
<p>ระดมทุนกับนักลงทุนที่ต้องการผลตอบแทนแต่เราต้องรักษากิจการไว้</p>
</li>
<li>
<p>หรือแม้แต่…เจรจาเรื่อง “เวลา” กับครอบครัว</p>
</li>
</ul>
<p>พูดง่าย ๆ คือ <strong>ถ้าคุณยังทำธุรกิจอยู่ คุณกำลังเจรจาต่อรองอยู่ทุกวัน</strong> เพียงแค่บางครั้งคุณอาจไม่รู้ตัว</p>
<p>
<hr />
<h2></h2>
<h5>ความเข้าใจผิดเกี่ยวกับการเจรจาธุรกิจ</h5>
<p>เจ้าของร้านหลายคนพอพูดถึงคำว่า “การเจรจา” มักจะนึกถึงภาพว่า</p>
<ul>
<li>
<p>ต้องพูดให้แน่วแน่</p>
</li>
<li>
<p>ต้องต่อให้ได้ราคาต่ำที่สุด</p>
</li>
<li>
<p>ต้องทำยังไงก็ได้ให้เขายอม</p>
</li>
</ul>
<p>แต่นั่นคือ “กับดัก” ที่ทำให้การเจรจาล้มเหลว เพราะการเจรจาที่ดีไม่ใช่การชนกันจนแพ้-ชนะ แต่คือการ <strong>หาทางออกที่ทุกฝ่ายได้ประโยชน์ร่วมกัน (Win-Win Solution)</strong></p>
<p>ลองเปลี่ยนจาก mindset “ชนะเขา” เป็น mindset “หาทางไปต่อด้วยกัน” คุณจะเจรจาเก่งขึ้นทันที</p>
<p>
<hr />
<h2></h2>
<h5>3 เสาหลักของการเจรจาแบบมืออาชีพ</h5>

<h6>1. การเตรียมตัว: ไม่ได้คุยเก่งก็ชนะได้ ถ้าเตรียมมาดี</h6>
<p>ก่อนคุยทุกครั้ง ถามตัวเองให้ครบ 3 ข้อนี้:</p>
<ul>
<li>
<p>เราต้องการอะไรจริง ๆ? (เป้าหมายหลักของเราคืออะไร และอะไรคือจุดที่เรารับไม่ได้)</p>
</li>
<li>
<p>เขาต้องการอะไร? (เจรจาเก่งคือเจรจาแบบเข้าใจความคิดอีกฝ่าย)</p>
</li>
<li>
<p>ถ้าคุยไม่ลงตัว เราจะทำยังไง? (นี่คือ BATNA &#8211; Best Alternative to a Negotiated Agreement)</p>
</li>
</ul>
<p>ใครมีแผนสำรองที่ดี ก็เท่ากับว่ามีอำนาจต่อรองในห้องคุยมากขึ้น</p>
<h3></h3>
<h6>2. การสื่อสาร: ไม่ใช่แค่พูดดี แต่ต้องฟังให้เป็น</h6>
<p>เจรจาเก่ง ไม่ได้เท่ากับพูดเก่ง แต่จริง ๆ คือ <strong>ฟังเก่ง และเข้าใจสิ่งที่ไม่ได้พูดออกมาตรง ๆ</strong> เช่น</p>
<ul>
<li>Active Listening</li>
<li>คำถามปลายเปิด เช่น “ถ้าเราปรับดีลตรงนี้ คุณคิดว่าโอเคขึ้นไหมครับ?”</li>
<li>การใช้ภาษากาย น้ำเสียง สีหน้า ท่าทาง สำคัญพอ ๆ กับคำพูด</li>
<li>ใช้คำว่า “เรา” แทน “คุณ” ช่วยสร้างบรรยากาศเป็นมิตร</li>
</ul>
<p>
<h6>3. การหาทางออก: มองลึกกว่าตำแหน่ง แต่เข้าใจความต้องการแท้จริง</h6>
<ul>
<li>
<p>ถ้าลูกค้าไม่อยากจ่ายแพง ลองเพิ่มของแถมหรือบริการเสริมที่ต้นทุนเราต่ำ แต่เขารู้สึกคุ้ม</p>
</li>
<li>
<p>ถ้า Supplier ไม่ลดราคา ก็ให้เพิ่มเสนอซื้อเยอะขึ้นหรือต่อเครดิตแทน</p>
</li>
</ul>
<p>เพราะการเจรจาที่ดีไม่ใช่แค่ “ใช่” หรือ “ไม่ใช่” แต่มันคือการ <strong>สร้างทางเลือกที่หลากหลาย</strong> ให้เดินไปต่อได้ด้วยกัน</p>

<hr />
<h2></h2>
<h5>ทริคเล็ก ๆ ที่ช่วยให้เราดูเจรจาเก่งขึ้นทันที</h5>
<ul>
<li>
<p>เงียบให้เป็น บางทีการไม่พูดอะไรเลยหลังจากอีกฝ่ายพูดจบ จะทำให้เขาเผยไพ่ลึกขึ้น</p>
</li>
<li>
<p>ยอมเล็กเพื่อได้ใหญ่ เช่น ของแถม ขนส่งฟรี</p>
</li>
<li>
<p>ใช้เทคนิค Labeling เช่น “ฟังดูเหมือนคุณอยากได้ดีลที่ง่ายและไม่ซับซ้อนใช่ไหมครับ?”</p>
</li>
</ul>

<h5><strong>Negotiation Skill คือ Soft Skill ที่แข็งที่สุด</strong></h5>
<p>ทักษะการเจรจาต่อรองไม่ใช่แค่ช่วยคุณ “ลดต้นทุน” หรือ “ปิดดีล” แต่ยังช่วยคุณ <strong>รักษาความสัมพันธ์ที่ดี</strong> ซึ่งคือรากฐานสำคัญของการทำธุรกิจให้ยั่งยืน</p>
