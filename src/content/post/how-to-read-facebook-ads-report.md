<h4>วิธีดูค่าโฆษณา Facebook Ads ให้คุ้มทุกบาท ด้วย 6 Metrics ที่คนยิงแอดต้องรู้</h4>
<p>
<p>ยิงแอดไม่ปัง ไม่ได้แปลว่าระบบแย่เสมอไป แต่บ่อยครั้งเป็นเพราะคนยิงแอด “อ่านตัวเลขไม่เป็น” ทำให้วิเคราะห์ผิดทาง ปรับผิดจุด และเผางบ marketing แบบไม่รู้ตัว</p>
<p>การรู้ <strong>วิธีดูค่าโฆษณา Facebook Ads</strong> จึงเป็นทักษะสำคัญของเจ้าของร้าน และนักการตลาดทุกคน เพราะตัวเลขคือภาษาที่บอกว่าแอดของเรากำลังมาถูกทางหรือกำลังพาเราขาดทุน</p>
<p>นี่คือ <strong>6 ค่าแอดที่ต้องดูให้เป็น</strong> และเป็นหัวใจของการอ่าน Report Facebook Ads ให้ถูกต้อง</p>


<h5><strong>1. CTR (Click Through Rate) วัดว่าแอดน่าสนใจจริงไหม</strong></h5>
<p>CTR คือเปอร์เซ็นต์ของคนที่เห็นแล้วคลิก ใช้บอกคุณภาพของคอนเทนต์แบบตรงไปตรงมา</p>
<h6>ถ้า CTR ต่ำกว่า 1% แปลว่าอะไร</h6>
<ul>
<li>
<p>ภาพไม่เด่น</p>
</li>
<li>
<p>Hook ไม่แรง</p>
</li>
<li>
<p>ข้อความไม่โดนใจ</p>
</li>
<li>
<p>คอนเทนต์ไม่สร้างแรงจูงใจพอ</p>
</li>
</ul>
<h6>วิธีแก้ CTR ต่ำ</h6>
<ul>
<li>
<p>ปรับ Hook ภาพ<!-- notionvc: 0ae93012-5518-41f0-8b4a-46a8f53a1adf --></p>
</li>
<li>
<p>เขียน Headline ใหม่</p>
</li>
<li>
<p>ดึง Pain Point หรือ Benefit ให้ชัด</p>
</li>
<li>
<p>ทดสอบรูปแบบวิดีโอสั้น</p>
</li>
</ul>
<p>CTR คือด่านแรกที่ต้องอ่านให้เป็น เพราะมันชี้ว่าแอด “ดึงดูด” ได้หรือไม่</p>


<h5><strong>2. CPC (Cost per Click) ต้นทุนต่อคลิกที่บอกความคุ้มค่า</strong></h5>
<p>แม้ CTR ดี แต่ถ้า CPC แพงเกินไป การยิงแอดก็ไม่คุ้มค่า</p>
<h6>ถ้า CPC เกิน 10 บาท ต้องเช็กทันที</h6>
<ul>
<li>
<p>กลุ่มเป้าหมายแคบเกินไปรึเปล่า</p>
</li>
<li>
<p>คอนเทนต์ไม่ตรงกับความสนใจ</p>
</li>
<li>
<p>ช่วงเวลานั้นคู่แข่งยิงเยอะ</p>
</li>
</ul>

<h6>ปรับยังไงให้ CPC ลด</h6>
<ul>
<li>
<p>ขยายกลุ่มเป้าหมาย</p>
</li>
<li>
<p>ใช้ภาพ/ข้อความที่ “เรียบง่าย” และเข้าใจเร็ว</p>
</li>
<li>
<p>ลดตัวหนังสือในภาพ</p>
</li>
</ul>
<p>CPC ใช้บอกคุณภาพของผู้ชมที่เราจ่ายเงินไปหา ว่าแพงเกินไปไหมเมื่อเทียบกับโอกาสปิดการขายจริง</p>
<p>
<p>
<h5><strong>3. CPM (Cost per 1,000 Impressions) วัดระดับการแข่งขันในตลาด</strong></h5>
<p>CPM คือค่าการมองเห็น 1,000 ครั้ง ใช้บอกว่าตลาดช่วงนั้นแข่งขันหนักแค่ไหน</p>
<h6></h6>
<h6>ถ้า CPM สูง แปลว่าอะไร</h6>
<ul>
<li>
<p>คู่แข่งในกลุ่มเดียวกันลงงบเยอะ</p>
</li>
<li>
<p>เป็นช่วงเทศกาลหรือ High Season</p>
</li>
<li>
<p>ระบบมองว่าคอนเทนต์เรายังไม่โดดเด่น</p>
</li>
</ul>
<h6></h6>
<h6>วิธีดูค่าโฆษณา Facebook Ads ผ่านมุมของ CPM</h6>
<p>ถ้า CPM สูง ไม่ต้องเพิ่มงบ แต่ต้องเพิ่ม “ความแตกต่าง”</p>
<ul>
<li>
<p>ทำครีเอทีฟที่ฉีก</p>
</li>
<li>
<p>เขียนข้อความที่ดักปัญหาตรง ๆ</p>
</li>
<li>
<p>ทำวิดีโอ 3–6 วินาทีที่คนหยุดดู</p>
</li>
</ul>
<p>ตลาดแข่งด้วยไอเดีย ไม่ใช่เงิน</p>
<p>
<p>
<h5><strong>4. Pageview / Add to Cart ตรวจสอบคุณภาพ Landing Page</strong></h5>
<p>ตัวเลขนี้บอกว่า “แอดทำงานแล้ว แต่หน้าขายปิดงานได้ไหม”</p>
<h6>ถ้าคนคลิกเข้ามาเยอะ แต่ไม่ซื้อ แปลว่า</h6>
<ul>
<li>
<p>หน้าเว็บโหลดช้า</p>
</li>
<li>
<p>ไม่ตอบคำถามลูกค้า เช่น ราคา โปรโมชั่น ความน่าเชื่อถือ</p>
</li>
<li>
<p>ปุ่มชวนซื้อซ่อนอยู่</p>
</li>
<li>
<p>ขั้นตอนซื้อเยอะเกินไป</p>
</li>
</ul>
<h6>สิ่งที่ควรปรับใน Landing Page</h6>
<ul>
<li>
<p>จัดลำดับข้อมูลให้กระชับ</p>
</li>
<li>
<p>เพิ่มรีวิวจริง</p>
</li>
<li>
<p>ทำปุ่ม Call to Action ให้เด่น</p>
</li>
<li>
<p>ลดขั้นตอน checkout</p>
</li>
</ul>
<p>อย่าปรับแต่แอด ทั้งที่ตัวปัญหาอยู่หน้าบ้านเรานี่เอง</p>
<p>
<p>
<h5><strong>5. Conversion Rate &amp; ROAS วัดผลลัพธ์จริง ไม่ใช่ความรู้สึก</strong></h5>
<p>ตัวเลขนี้คือหัวใจของ <strong>วิธีดูค่าโฆษณา Facebook Ads</strong> เพราะมันบอกเลยว่ายิงแล้วได้เงินกลับมาหรือเปล่า</p>
<h6>ตัวอย่างการอ่าน ROAS</h6>
<ul>
<li>
<p>ยิง 1,000 บาท ได้ยอดขาย 3,000 = ROAS 3 ดี</p>
</li>
<li>
<p>ยิง 1,000 บาท ได้ยอดขาย 500 = ขาดทุน</p>
</li>
</ul>

<h6>ดูให้ครบ ไม่ใช่ดูแค่ยอดขาย</h6>
<p>เวลาคิดกำไรจริงต้องรวม</p>
<ul>
<li>
<p>COGS (ต้นทุนสินค้า)</p>
</li>
<li>
<p>ค่าบรรจุภัณฑ์</p>
</li>
<li>
<p>ค่าขนส่ง</p>
</li>
<li>
<p>ค่า Payment Gateway</p>
</li>
</ul>
<p>แล้วค่อยสรุปว่าควร “เพิ่มงบ” หรือ “หยุดแคมเปญ”</p>
<p>
<p>
<h5><strong>6. Frequency ความถี่ที่คนเห็นแอด</strong></h5>
<p>Frequency คือจำนวนครั้งโดยเฉลี่ยที่คนเดิมเห็นแอดของเรา</p>
<h6>กฎง่าย ๆ</h6>
<ul>
<li>
<p>เห็นเกิน 3 ครั้ง คนเริ่มล้า</p>
</li>
<li>
<p>CTR จะตกลง</p>
</li>
<li>
<p>แอดจะเริ่มตัน</p>
</li>
</ul>
<h6>ถ้า Frequency สูงต้องทำสิ่งนี้</h6>
<ul>
<li>
<p>เปลี่ยนครีเอทีฟ</p>
</li>
<li>
<p>ปรับข้อความ</p>
</li>
<li>
<p>หาลูกค้ากลุ่มใหม่</p>
</li>
<li>
<p>รีเซ็ตแคมเปญถ้าจำเป็น</p>
</li>
</ul>
<p>ถ้าปล่อยให้เห็นซ้ำมากเกินไป ระบบจะคิดว่าแอดไม่ดีและจะยิ่งยิงแพงขึ้น</p>
