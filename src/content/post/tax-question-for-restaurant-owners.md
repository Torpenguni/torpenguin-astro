<h4><span><strong>คำถามเรื่องภาษี เปิดร้านมา 3 ปีไม่เคยเสียภาษี พอปีที่ 4 จดบริษัท ต้องเสียย้อนหลังไหม?</strong></span></h4>

<p>นี่คือ <strong>คำถามเรื่องภาษี</strong> ที่เจ้าของร้านอาหารจำนวนมากสงสัย<br />เปิดร้านมาหลายปีไม่เคยเสียภาษี พอเริ่มตั้งหลักได้และอยากทำให้ถูกต้องจึงไป<a href="https://torpenguin.com/%e0%b8%97%e0%b8%b3%e0%b8%a3%e0%b9%89%e0%b8%b2%e0%b8%99%e0%b9%81%e0%b8%9a%e0%b8%9a%e0%b9%84%e0%b8%ab%e0%b8%99%e0%b8%88%e0%b9%88%e0%b8%b2%e0%b8%a2%e0%b8%a0%e0%b8%b2%e0%b8%a9%e0%b8%b5%e0%b8%99%e0%b9%89/">จดบริษัท</a>ในปีที่ 4 แล้วอดีต 3 ปีที่ผ่านมา…ต้องเสียภาษีย้อนหลังหรือไม่</p>
<p>คำตอบคือ <strong>ต้องเสียค่ะ</strong></p>
<p>หลายคนไม่อยากฟัง แต่เป็นเรื่องที่ต้องยอมรับ เพราะการทำธุรกิจไม่ได้ต่างอะไรกับกฏของธรรมชาติ<br />คุณไม่สามารถ &#8220;ทำบุญลบล้างบาป&#8221; ได้<br />บาปอะไรที่เคยทำไว้…มันไม่หายไปไหน เพียงแค่ยังไม่มีใครเห็นเท่านั้นเอง</p>
<p>ภาษีก็เหมือนกัน<br />ต่อให้วันนี้คุณจะอยากเริ่มต้นใหม่ให้ถูกต้อง แต่สิ่งที่ทำมาแล้วในอดีตก็ยังคงอยู่<br />และเมื่อคุณจดทะเบียนบริษัทเมื่อปีที่ 4 นั่นไม่ได้ทำให้ภาษีในอดีตหายไปเลย</p>


<h5>ทำไมเปิดร้านมา 3 ปีไม่เคยเสียภาษี ถึงยังต้องเสียย้อนหลัง</h5>
<p>แม้ร้านอาหารหลายร้านจะเริ่มต้นจากร้านเล็ก ๆ ขายไม่กี่จานต่อวัน แต่เมื่อธุรกิจเติบโต มีลูกค้าเยอะขึ้น เริ่มเป็นที่รู้จัก หรือมีการขายผ่านแอปดิลิเวอรี่ ข้อมูลทั้งหมดเหล่านี้จะเข้าไปอยู่ในระบบของ <strong>สรรพากรพื้นที่</strong> เรียบร้อยแล้ว</p>
<p>ต่อให้ร้านคุณไม่เคยถูกตรวจมาก่อน ก็ไม่ได้หมายความว่าจะไม่มีวันถูกตรวจ<br />การจดบริษัทไม่ใช่ “การล้างข้อมูลเก่า” แต่อาจกลายเป็น “การเริ่มปรากฏตัวในระบบ” ต่างหาก</p>
<p>สรรพากรไม่ได้รู้กำไรแท้จริงของร้านคุณ<br />แต่สิ่งที่เค้าทำได้คือ <strong>ประเมินย้อนหลัง</strong> และสิ่งนี้ต่างหากที่ทำให้เจ้าของร้านจำนวนมากไปต่อไม่ไหว</p>


<h5>แล้วสรรพากรประเมินยอดขายย้อนหลังยังไง</h5>
<p>สรรพากรมีวิธีการประเมินที่ทำได้จริง โดยใช้วิธีสังเกตการณ์และตรวจนับ เช่น</p>
<ul>
<li>
<p>นับจำนวนลูกค้าเฉลี่ยต่อวัน</p>
</li>
<li>
<p>ประเมินค่าใช้จ่ายเฉลี่ยของบิล</p>
</li>
<li>
<p>ตรวจสอบราคาอาหารในร้าน</p>
</li>
<li>
<p>ดูการขายบนแอปดิลิเวอรี่ย้อนหลัง</p>
</li>
<li>
<p>ตรวจสอบกระแสออนไลน์และรีวิว</p>
</li>
<li>
<p>ประเมินจำนวนพนักงานและรอบการหมุนของโต๊ะ</p>
</li>
</ul>
<p>จากนั้นจะคำนวณเป็นยอดขายเฉลี่ยต่อวัน × จำนวนวันที่เปิดร้านตั้งแต่ปีแรก</p>
<p>และสรรพากรมักตั้งสมมติฐานต้นทุนร้านอาหารประมาณ <strong>60%</strong><br />แปลว่า <strong>กำไรขั้นต้นถูกตีไว้ที่ 40%</strong></p>
<p>หากคุณไม่มีหลักฐานใด ๆ ไปโต้แย้ง เช่น</p>
<ul>
<li>
<p>บัญชีรายรับรายจ่าย</p>
</li>
<li>
<p>บิลซื้อวัตถุดิบ</p>
</li>
<li>
<p>รายงานยอดขายจริง</p>
</li>
<li>
<p>หลักฐานการปิดร้านในบางวัน</p>
</li>
<li>
<p>หรือหลักฐานอื่น ๆ ที่พิสูจน์ว่ารายได้ต่ำกว่าในประเมิน</p>
</li>
</ul>
<p>คุณก็จะต่อรองได้ยาก และอาจต้องยอมรับยอดภาษีและค่าปรับก้อนใหญ่ตามการประเมินนั้นทันที</p>


<h5>วิธีลดความเสี่ยงเรื่องภาษีย้อนหลังของร้านอาหาร</h5>

<h6><span>1) เก็บเอกสารให้ครบตั้งแต่วันนี้เป็นต้นไป</span></h6>
<p>แม้อดีตแก้ไม่ได้ แต่คุณเริ่มเก็บหลักฐานวันนี้ได้ทันที เช่น</p>
<ul>
<li>
<p>บิลซื้อวัตถุดิบ</p>
</li>
<li>
<p>รายรับรายจ่าย</p>
</li>
<li>
<p>รายงานยอดขาย POS</p>
</li>
<li>
<p>ภาพถ่ายการปิดร้านในบางวัน</p>
</li>
<li>
<p>หลักฐานค่าใช้จ่ายอื่น ๆ</p>
</li>
</ul>

<h6><span>2) จดบริษัทไม่ได้ช่วยลบความผิดเก่า</span></h6>
<p>การจดบริษัทเป็นเรื่องดี แต่ไม่ได้ “ล้างข้อมูล” ของการทำธุรกิจในอดีต<br />ภาษีเก่ายังคงต้องจ่ายหากมีการตรวจพบ</p>
<h6><span>3) เร่งเคลียร์ภาษีให้ถูกต้องโดยเร็วที่สุด</span></h6>
<p>ยิ่งนานวัน ยอดปรับยิ่งทบกัน<br />การจัดระบบภาษีตั้งแต่ตอนนี้คือการปิดประตูความเสี่ยงในอนาคต</p>


<h5>อย่าคิดว่าโชคดีที่ไม่โดนจับ</h5>
<p>หลายคนคิดว่า “เปิดมาตั้งนานแล้ว ไม่เห็นโดนอะไร” จึงปล่อยไปเรื่อย ๆ<br />แต่วันหนึ่งเมื่อมีสัญญาณความเติบโต เช่น</p>
<ul>
<li>
<p>การรีวิวเยอะขึ้น</p>
</li>
<li>
<p>ยอดขายเดลิเวอรี่สูงขึ้น</p>
</li>
<li>
<p>ร้านเริ่มเป็นที่รู้จักในพื้นที่</p>
</li>
</ul>
<p>คุณจะกลายเป็น “จุดสนใจ” ในทันที</p>
<p>การทำให้ถูกต้องเสียแต่วันนี้ง่ายกว่า ถูกกว่า และปลอดภัยกว่าในระยะยาว</p>


<p>หวังว่าบทความนี้จะตอบคำถามคาใจของใครหลายคน และเป็นประโยชน์ให้กับผู้ประกอบการทุกท่านนะคะ ฝากติดตาม Torpenguin ในทุก ๆ ช่องทางด้วยนะคะ แล้วพบกันใหม่ในบทความหน้าค่ะ 🤗🐧</p>
