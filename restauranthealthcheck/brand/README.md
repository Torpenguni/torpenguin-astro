# ไฟล์โลโก้ต้นฉบับ

โฟลเดอร์นี้อยู่นอก `public/` จึงไม่ถูกส่งขึ้นเว็บ เก็บไว้เป็นต้นฉบับเฉย ๆ
ไฟล์ที่เว็บใช้จริงอยู่ที่ `public/logos/`

| ไฟล์ | คืออะไร |
|---|---|
| `penguinx-for-light-bg.png` | ตัวหนังสือดำ + X ทอง ใช้บนพื้นสว่าง — ต้นฉบับของ `public/logos/penguinx.png` |
| `penguinx-for-dark-bg.png` | ตัวหนังสือขาว ใช้บนพื้นเข้มเท่านั้น ยังไม่ได้ใช้ที่ไหน |
| `cp-original.png` | ต้นฉบับของ `public/logos/cp.png` |

ทั้งสามไฟล์ส่งมาเป็น PNG พื้นขาวทึบ ไม่มีความโปร่งใส ถ้าเอาไปวางบนพื้นครีม
ของเว็บจะเห็นเป็นกล่องขาวล้อมรอบ ไฟล์ใน `public/logos/` จึงเป็นเวอร์ชันที่
ลอกพื้นขาวออกและไล่ขอบให้เนียนแล้ว ตัวโลโก้ไม่ได้ถูกแก้สีหรือสัดส่วนใด ๆ

ถ้าวันหนึ่งได้ไฟล์ `.svg` มาให้เปลี่ยนไปใช้แทน จะคมกว่านี้และไฟล์เล็กกว่ามาก
